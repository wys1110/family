# 여행 관리 개선

사용자가 승인한 구성: 전체 요약과 여행 관리를 분리하고 검색, 상태 필터, 보관한 여행 복원을 제공한다.

1. 기존 날짜 집계를 재사용하는 목록 모듈을 추가한다. 진행 중, 가까운 예정, 최근 지난 여행 순으로 정렬하고 보관된 여행을 별도 필터에 표시한다.
2. 여행 관리 목록을 기본 화면으로 열고 상세 일정과 목록 사이를 이동한다. 검색어와 필터는 유지한다. 전체 요약의 점 지도와 기존 일정 편집을 보존한다.
3. 복원, 새 여행, 정보 편집, 보관 흐름을 검증한다. 검색 입력 시 결과만 갱신하여 입력 초점을 유지한다.
4. 관련 테스트, 전체 테스트와 정적 검사 후 가상 데이터로 모바일/데스크톱 브라우저를 확인한다. GitHub PR을 통해 배포하고 공개 데모 화면을 검증한다.

데이터 모델과 공유 정책은 변경하지 않는다. 실제 가족 데이터 대신 로컬 가상 데이터와 공개 데모를 사용한다.
