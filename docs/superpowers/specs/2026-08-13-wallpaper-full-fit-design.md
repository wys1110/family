# 일정·성장 월페이퍼 전체 표시 설계

## 목표

모바일 일정·성장 카드에서 가족 월페이퍼가 카드 비율에 맞춰 잘리지 않고 전체가 보이도록 한다.

## 설계

- 월페이퍼 사진 레이어는 `cover` 대신 `contain`으로 렌더링한다.
- 사진은 카드 오른쪽 중앙에 배치한다. 텍스트가 있는 왼쪽 영역을 덜 침범하면서 사진 전체를 유지한다.
- 사진 주변에 남는 공간은 기존 카드 배경을 사용한다.
- 가독성 그라데이션은 카드 전체를 계속 덮도록 별도 배경 레이어 크기를 `100% 100%`로 유지한다.
- 일정·성장 카드 모두 같은 규칙을 사용한다. 성장 카드의 중립 색상·텍스트 대비 보정은 그대로 유지한다.

## 변경 범위

- `family-wallpapers.css`: 다중 배경 레이어의 크기·위치·반복 규칙 수정
- `test/household-wallpapers.test.js`: 사진 전체 표시와 새 CSS 자산 버전 회귀 테스트
- `config.js`: 월페이퍼 CSS 캐시 버전 갱신

## 제외 범위

- 카드 높이, 텍스트, 버튼 위치, 사진 저장 방식, 가족별 데이터 격리 로직은 변경하지 않는다.
- 사용자가 사진 초점을 직접 조절하는 기능은 추가하지 않는다.

## 검증

- 회귀 테스트가 그라데이션과 사진 레이어의 서로 다른 크기를 확인한다.
- 전체 테스트와 정적 검사를 통과시킨다.
- 390px 모바일 화면에서 일정·성장 카드의 사진 전체 표시와 글자 가독성을 확인한다.
