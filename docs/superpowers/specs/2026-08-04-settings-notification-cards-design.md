# 설정 화면 알림 카드 제거 설계

## 목표

사용하지 않는 설정 항목을 줄이기 위해 설정 화면에서 알림 관련 카드와 기존 불필요 카드만 제거하고, 알림 기능의 실제 코드·데이터·서비스워커는 보존한다.

## 범위와 동작

- `새로고침` 카드와 `최근 활동 기록` 안내는 기존처럼 설정 화면에 노출하지 않는다.
- `가족 일정 앱 알림` 카드와 `수유 알림` 카드는 설정 화면에 노출하지 않는다.
- 일정 변경 알림, 아침 브리핑, 수유 알림의 모듈·저장값·서비스워커 동작은 삭제하지 않는다.
- 가족 정보, 화이트/다크 테마, 일정 글자 크기는 계속 노출한다.
- 설정 화면 외 상단 알림 버튼과 알림 목록은 영향을 주지 않는다.

## 구현 방향

기존 동적 카드 ID를 이용해 `#settingsView` 직속 카드만 CSS로 숨긴다. 설정 모듈 캐시 버전을 갱신하고, 정적 테스트로 네 카드의 숨김 선택자와 알림 모듈 생성 코드 보존을 검증한다.

## 검증 기준

1. 네 카드가 설정 화면에서 `display: none !important` 상태다.
2. 알림 모듈의 설정 카드 생성 코드는 유지된다.
3. 테마·글자 크기·가족 정보 카드는 계속 표시된다.
4. 전체 테스트, 검사, 브라우저 확인, Pages 배포가 성공한다.
