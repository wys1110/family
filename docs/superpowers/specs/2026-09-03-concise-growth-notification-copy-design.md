# 간결한 성장 기록 알림 설계

## 목표

성장일기 알림에서 반복적인 안내 문구와 긴 카테고리를 제거하고, 실제 기록 내용과 기록자 호칭만 표시한다.

## 사용자 경험

- 계정 화면에서 현재 로그인 계정의 알림 호칭을 `엄마` 또는 `아빠`로 한 번 저장한다.
- 성장 기록 알림은 다음처럼 구체적인 값만 제목에 표시한다.
  - `모유 · 왼쪽 수유 · 20분 · 엄마`
  - `젖병 · 100ml · 아빠`
  - `기저귀 · 소변 · 엄마`
- 푸시 본문은 비워 제목과 내용이 중복되지 않게 한다.
- iOS가 알림에 자동으로 표시하는 `from 우리 가족` 표시는 앱 payload로 제어하지 않는다.

## 구현 경계

- 호칭은 Supabase Auth의 `user_metadata.family_role`에 저장한다. 이는 표시용 데이터이며 RLS나 권한 판단에 사용하지 않는다.
- Edge Function은 인증된 현재 사용자에서 호칭을 읽고, 클라이언트가 보낸 호칭을 신뢰하지 않는다.
- 성장·수유·수면·기저귀·건강 기록의 기존 변경 감지와 수신자 제외 규칙은 유지한다.
- 기록 값은 카테고리별로 필요한 값만 추린다. 측정 기록은 키·몸무게·머리둘레·체온, 수유는 종류·방향·시간·용량, 수면은 시간, 기저귀는 종류를 사용한다.
- 호칭이 설정되지 않은 계정은 기록 내용만 표시한다.

## 완료 조건

- 계정 화면에서 엄마/아빠 호칭을 저장할 수 있다.
- 서버 payload의 제목에 일반 문구가 없고 기록 내용만 있으며 본문은 빈 문자열이다.
- 저장된 호칭이 있는 경우 제목 끝에 호칭이 붙는다.
- 정적 검사와 전체 테스트가 통과한다.
