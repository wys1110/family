# 관리자 탭 시각·반응형 개선 설계

## 목표

관리자 화면을 화이트/다크 테마에서 같은 의미 토큰으로 보이게 하고, 모바일 조작 영역과 관리자 하위 카드의 폭을 통일한다.

## 범위

- 사용자 아바타는 영웅 카드의 짙은 색을 재사용하지 않고 `--surface`/`--surface-2`와 `--label`을 사용한다.
- 사용자/가족 그룹 전환 버튼과 관리자 새로고침 컨트롤은 최소 44px 조작 높이를 갖는다.
- 관리자 본체, 최근 활동 카드, 전체 요청 카드가 관리자 뷰의 가로 그리드와 모바일 새로고침 규칙을 공유한다.
- 인증, Supabase RPC, 데이터 shape, 관리자 탭 노출 조건은 변경하지 않는다.

## 성공 기준

- 화이트 테마에서 관리자 아바타에 `--theme-hero-start/end` 또는 흰색 고정 전경색이 남지 않는다.
- 모바일 관리자 컨트롤의 최소 높이가 44px이고, 새로고침 버튼이 카드 양끝까지 확장된다.
- 기존 관리자 레이아웃 테스트와 새 계약 테스트가 통과한다.

## 검증 경계

현재 데모 세션에는 Supabase 관리자 컨텍스트가 없어 인증된 관리자 화면을 직접 열 수 없다. 따라서 정적 계약·단위 테스트와 배포된 CSS/JS 응답을 확인하고, 실제 관리자 계정 화면 검증은 별도 증거로 남긴다.
