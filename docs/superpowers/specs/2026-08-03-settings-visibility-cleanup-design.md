# 설정 화면 불필요 항목 숨김 설계

## 목표

설정 화면에서 현재 사용자 조작 가치가 낮고 다른 UI와 역할이 겹치는 `새로고침` 카드와 운영 목적의 `최근 활동 기록` 안내만 노출하지 않는다.

## 범위와 동작

- 설정 화면에서만 두 카드가 숨겨진다.
- `settings-refresh.js`와 `activity-log.js`의 생성·동작 코드는 삭제하지 않는다.
- 화이트/다크 테마, 일정 글자 크기, 가족 일정 알림, 수유 알림, 가족 정보는 계속 노출한다.
- 플로팅 새로고침 버튼과 기존 운영 기록 로깅은 유지한다.

## 구현 방향

`settings.css`에 `#settingsView` 하위의 두 데이터 선택자만 대상으로 하는 숨김 규칙을 추가한다. 동적으로 삽입되는 카드의 데이터 속성은 기존 모듈 계약을 그대로 사용하고, 모듈 로딩과 캐시 무효화를 위해 Settings 스타일 버전을 갱신한다.

## 검증 기준

1. 정적 회귀 테스트가 두 선택자의 설정 화면 한정 숨김 규칙을 확인한다.
2. 새로고침·활동 기록 모듈의 생성 코드는 그대로 존재한다.
3. 전체 테스트, 타입/문법 검사, diff 공백 검사가 통과한다.
4. 브라우저에서 두 카드가 보이지 않고 나머지 설정 카드가 보이는 것을 확인한다.
