# 가족 앱 실사용 유틸리티 기능 설계

## 목표

가족 앱을 매일 열었을 때 필요한 정보를 더 빨리 찾고, 현재 가능한 범위에서
권한 오용과 알림 혼선을 줄인다. 기존 일정·성장·할 일·알림 데이터 모델과
가족별 RLS 경계를 유지하며, 외부 비밀값이나 새 서버 배포가 필요한 기능은
이번 범위에서 제외한다.

## 범위와 순서

### 1. 오늘 한눈에 보기

캘린더 화면 상단에 접히지 않는 소형 요약 카드를 추가한다.

- 오늘 일정 수와 가장 가까운 다음 일정
- 오늘 미완료 할 일 수
- 오늘 수유·수면·기저귀 요약
- 읽지 않은 알림 수
- 각 요약 항목을 누르면 기존 일정·성장·할 일·알림 화면으로 이동

요약은 현재 `state.events`, 성장 기록, 기존 할 일 모듈의 스냅샷,
알림 센터의 읽지 않은 수를 사용한다. 새 데이터를 복제하거나 별도 저장하지
않는다. 데이터가 없거나 모듈이 아직 준비되지 않은 경우 0/빈 상태를 표시하고
기존 화면 렌더링을 막지 않는다.

### 2. 통합 검색

상단 계정 영역 옆에 검색 버튼을 추가하고, 모바일에서는 시트 대화상자로 연다.

- 일정·성장 기록·할 일을 한 검색어로 검색
- 결과 유형 필터: 전체 / 일정 / 성장 / 할 일
- 결과에는 날짜, 제목, 담당 가족 또는 아기 이름을 표시
- 결과 선택 시 기존 수정 대화상자를 호출
- 현재 로그인한 가족 공간의 데이터만 대상으로 하며 검색어·결과를 서버나
  로컬 저장소에 보존하지 않는다.

검색은 이미 화면에 로드된 데이터를 우선 사용한다. 할 일 모듈이 비동기 로드
중이면 준비 완료 이벤트 후 결과를 갱신하고, 로드 실패 시 일정·성장 검색은
계속 사용할 수 있게 한다.

### 3. 최소 권한 보호

현재 `household_members.role`의 `owner`/`member` 의미를 유지하고, 새 역할 값은
추가하지 않는다.

- 구성원 관리, 백업 복원, 가족 데이터 내보내기 컨트롤은 owner에게만 노출
- member에게는 기존 일정·성장·할 일 기록 기능을 유지
- UI 가드는 현재 로그인 컨텍스트의 membership role을 기준으로 한다.
- 데이터베이스의 전 테이블 RLS를 새 역할 체계로 재작성하지 않는다. 따라서
  이번 변경은 기능 노출 최소화이며, 완전한 viewer/editor 보안 모델은 별도
  migration과 정책 검토 작업으로 남긴다.
- role 정보를 가져오지 못한 경우 안전하게 관리 컨트롤을 숨기고 일반 화면만
  제공한다.

### 4. 알림 보강

기존 `notification-center.js`와 `daily-briefing.js`를 재사용한다.

- 오늘 요약 카드에 알림 센터의 읽지 않은 개수를 표시
- 알림 센터의 예정/지난/새 알림 구분과 기존 중복 전달 방지 상태를 유지
- 브라우저 알림 권한, 서비스 워커, 푸시 연결 상태를 설정 화면에서 명확히
  표시
- VAPID 키, Edge Function, Cron이 없는 환경에서는 실제 백그라운드 푸시를
  성공한 것처럼 표시하지 않고, 앱 내 알림과 설정 안내만 제공

## 접근성·반응형

- 요약·검색·권한 상태·알림 상태는 텍스트로도 전달한다.
- 검색 버튼, 결과 행, 요약 항목은 최소 44px 터치 영역을 갖는다.
- 390px 폭에서 요약 카드를 2열 이하로 유지하고 가로 스크롤을 만들지 않는다.
- 다크/화이트 테마 모두 기존 의미 토큰을 사용하며 고정 색상을 추가하지 않는다.
- `prefers-reduced-motion`에서 검색 시트와 요약 상태 전환 애니메이션을 줄인다.

## 오류·데이터 경계

- 모든 계산은 현재 household 컨텍스트에 이미 로드된 행만 사용한다.
- household ID, 사용자 ID, access token, 비공개 사진 URL을 검색 인덱스나
  DOM 검색 결과에 넣지 않는다.
- 네트워크·모듈 로드 실패는 해당 카드의 빈 상태로 격리하고 기존 일정/성장
  화면은 계속 동작시킨다.
- 권한 정보가 없으면 owner 전용 동작을 실행하지 않는다.

## 테스트 계획

- 순수 선택 함수 테스트: 오늘 일정/할 일/돌봄/읽지 않은 알림 집계, 검색어·유형
  필터, 날짜 정렬
- DOM 계약 테스트: 오늘 요약 카드, 검색 버튼·시트, owner 전용 컨트롤, 알림
  상태 문구와 44px 터치 영역
- 기존 설정·알림·할 일·테마 테스트를 함께 실행
- `node --check`, `git diff --check`, `npm test` 실행
- 배포 후 데모 모드에서 요약·검색·알림 상태를 확인하고, 인증 없는 화면에서
  owner 전용 컨트롤이 노출되지 않는지 확인

## 제외 범위

- viewer/editor 역할 추가와 모든 데이터 테이블 RLS 재설계
- VAPID 키 발급, Edge Function·Cron 배포, 실제 잠금 화면 푸시 검증
- 가족 데이터의 서버 검색 인덱스나 별도 검색 테이블
