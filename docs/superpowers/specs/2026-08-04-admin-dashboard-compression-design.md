# 관리자 대시보드 압축 설계

## 목표

관리자 탭의 핵심 상태를 첫 화면에서 빠르게 읽고, 사용자·가족 그룹·요청·최근 활동·Supabase 사용량의 상세 목록은 필요한 경우에만 펼쳐서 확인한다. 기존 RPC, 권한 검증, 검색, 필터, 요청 상태 변경은 그대로 유지한다.

## 선택한 방향

1. **요약 우선 + 카드별 접기/펼치기 (선택)**
   - 각 카드의 헤더와 핵심 숫자는 항상 보인다.
   - 검색, 필터, 그래프, 목록은 카드 본문으로 묶고 기본 접힘 상태로 둔다.
   - 접기 상태는 화면 세션 동안만 유지하며 새로고침 시 안전한 기본값으로 돌아간다.
   - 기존 기능을 제거하지 않으면서 첫 화면 높이를 가장 크게 줄일 수 있다.

2. **탭별 단일 화면 전환**
   - 카드 하나만 보이고 다른 카드를 탭으로 전환한다.
   - 스크롤은 줄지만 요청/활동/사용량을 비교하기 어렵고, 기존 카드 접근성이 크게 바뀐다.

3. **CSS 높이 제한 + 내부 스크롤**
   - 카드 높이를 제한하고 목록만 내부 스크롤한다.
   - 구현은 작지만 스크롤이 사라지는 것이 아니라 작은 영역으로 이동하고, 모바일에서 이중 스크롤이 생긴다.

## 화면 구성

- 상단 카드: `앱 전체 사용자 관리`
  - 헤더, 새로고침, 4개 통계(전체 사용자/가족 그룹/그룹 미가입/30일 내 로그인)는 기본 노출
  - 검색, 사용자·가족 그룹 전환, 상세 목록, 안내 문구는 접을 수 있는 본문
- 동적 관리자 카드 3개:
  - `Supabase 사용량`: DB/Storage 요약 수치만 기본 노출, 상태 메시지와 상세 게이지는 본문
  - `전체 사용자 요청`: 전체/처리 필요/완료 요약만 기본 노출, 검색·필터·상태 변경 목록은 본문
  - `최근 사용자 활동`: 조회 기간 활동/활동 사용자/오늘 활동 요약만 기본 노출, 사용자 그래프·검색·기간·목록은 본문
- 모든 카드 헤더에 동일한 `접기`/`펼치기` 버튼을 배치한다.
- 버튼은 `aria-expanded`, `aria-controls`를 제공하고 키보드 포커스를 유지한다.
- 카드 본문은 `data-admin-card-body`로 식별하고 `data-admin-collapsed="true"`일 때만 숨긴다.
- 색상은 기존 semantic theme token을 사용해 화이트/다크 모드 모두 동일한 역할 대비를 유지한다.

## 데이터 흐름과 오류 처리

- 기존 RPC 호출과 오류/권한 경계는 변경하지 않는다.
- 로딩/오류 상태는 카드 본문에 남겨 새로고침 및 오류 안내를 계속 사용할 수 있게 한다.
- 접기 상태는 데이터 로드와 독립적이다. 로드 실패 시에도 헤더와 상태 버튼은 보인다.
- 상세가 접혀 있어도 기존 데이터 로드는 유지해 펼칠 때 지연을 만들지 않는다.

## 테스트와 검증

- 정적 계약 테스트로 다섯 관리자 카드가 `data-admin-collapse`, `data-admin-card-body`, `aria-expanded` 계약을 갖는지 검증한다.
- 기존 관리자/요청/활동 테스트를 함께 실행한다.
- `node --check`와 `git diff --check`를 실행한다.
- 인증된 관리자 화면에서 모바일 폭을 기준으로 상단 요약 높이, 카드 토글, 가로 넘침, 화이트/다크 토큰을 확인한다.
