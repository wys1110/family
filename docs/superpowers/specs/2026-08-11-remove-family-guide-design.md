# 가이드 탭 제거 설계

## 결정

준비·육아 가이드 기능을 앱에서 완전히 제거한다. 메뉴 탭만 숨기지 않고, 동적으로 만드는 화면, 정적 안내 데이터, 스타일, 모듈 등록, 관련 테스트와 설정 참조를 함께 삭제한다.

## 범위

- 유지: 일정, 성장, 동화, 요청, 설정, 관리 기능과 가족·아기 데이터
- 삭제: 가이드 탭, `#guideView`, `family-guide.js`, `family-guide-data.js`, `family-guide.css`, 가이드 전용 테스트
- 삭제: 가이드 모듈을 로드하는 `config.js` 항목, 탭 이모지와 설정 화면의 가이드 뷰 참조
- 유지하지 않음: 숨김 탭, 유휴 데이터 파일, 레거시 가이드 설정을 읽는 호환 경로

## 검증

- 앱 설정에 `family-guide` 또는 `family-guide-data` 모듈이 남지 않는다.
- 메뉴와 설정 화면에 가이드 노출이 남지 않는다.
- 전체 테스트와 정적 검사에서 삭제된 파일 참조가 발생하지 않는다.
