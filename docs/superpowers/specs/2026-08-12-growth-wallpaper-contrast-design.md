# 성장 월페이퍼 대비 수정 설계

## 문제

화이트 테마의 `.baby-profile-card` 규칙이 사진이 적용된 카드에도 뒤에서 적용되며 카드 글자를 어두운 색으로 되돌린다. 사진 위 전체 색조와 검정 글자가 겹쳐 사진 색감과 정보 가독성이 동시에 저하된다.

## 승인된 방향

성장 사진 카드는 사진 자체의 색을 유지한다. 카드 전체를 색으로 덮지 않고, 텍스트가 있는 왼쪽에서 오른쪽으로 투명해지는 중립적인 검정 그라데이션만 사용한다. 카드 내부 제목·날짜·D-day는 흰색 계열로 고정하고 기존 텍스트 그림자를 유지한다. 사진 변경·삭제 버튼은 현재 하단 우측 위치와 반투명 검정 표면을 유지한다.

## 범위

- `family-wallpapers.css`에서 사진이 있는 성장 프로필 카드만 구체적으로 보정한다.
- 화이트·다크 모두 같은 사진 중심 표현을 사용하되 기존 테마 토큰을 소비한다.
- 사진 업로드, 저장 위치, DB, Storage, 크롭 로직은 변경하지 않는다.
- 사진이 없는 기본 성장 카드와 일정 월페이퍼는 변경하지 않는다.

## 검증

- CSS 계약 테스트로 성장 사진 카드의 선택자, 왼쪽 그라데이션, 흰색 텍스트 우선순위를 고정한다.
- 전체 테스트와 정적 검사를 실행한다.
- 390×844 모바일 화면에서 화이트·다크 성장 카드와 브라우저 콘솔을 확인한다.
