# 블랙 테마 주말 요일 색상 디자인

## 목표

타임트리 다크모드처럼 블랙 테마 캘린더에서 일요일을 빨강, 토요일을 파랑으로 표시해 주말을 빠르게 구분한다.

## 범위

- `html[data-family-theme-choice="black"]` 아래 캘린더에만 적용한다.
- 요일 헤더와 날짜 숫자 모두에 적용한다.
- 일요일은 `#ff6b78`, 토요일은 `#6ea8ff`를 사용한다.
- 현재 날짜, 선택 날짜, 공휴일, 일정 블락의 기존 우선순위와 멤버 색상은 유지한다.
- 별빛 밤과 라이트 테마에는 영향을 주지 않는다.

## 구현 방향

캘린더 렌더러가 이미 일요일부터 토요일 순서로 `.weekdays span`과 `.calendar-day`를 생성하므로 런타임 로직은 변경하지 않는다. 블랙 테마 전용 CSS에서 첫 번째/일곱 번째 열을 선택해 헤더와 날짜 숫자에 색상을 적용한다. 날짜 숫자는 `.calendar-day:not(.today) .day-number`로 제한해 오늘 원형 배지의 흰색 가독성을 보존한다.

## 검증 기준

- 테마 회귀 테스트가 토요일 파랑·일요일 빨강 전용 선택자와 색상 토큰을 보장한다.
- 관련 테마 테스트와 정적 검사에 통과한다.
- 390px 데모 브라우저에서 블랙 테마를 선택했을 때 헤더와 날짜 숫자가 의도한 색상으로 계산된다.
