# 설정 관리 기능 디자인

## 목표

설정 화면에서 가족 구성원, 가족 공간, 데이터를 안전하게 관리할 수 있게 한다. 기존 화이트/다크 테마와 Excel 내보내기는 유지하고, 알림 설정은 다시 노출하지 않는다.

## 현재 구조

- `family-profile.js`: 가족 사진과 아빠·엄마·아이 표시 이름을 기기별로 저장한다.
- `settings.js`: 화이트/다크 테마만 제공한다.
- `settings-data-export.js`: 현재 `household_id`의 일정과 성장 기록을 두 개의 Excel 시트로 내보낸다.
- `app.js`: `calendar_members`를 일정 입력 화면에서 추가하고 계정 창에서 로그아웃·초대 코드를 제공한다.
- 설정 CSS는 알림·활동 공개·별도 새로고침 카드를 의도적으로 숨긴다.

## 결정한 범위

### 1. 가족 구성원 관리

설정에 현재 가족 구성원 목록을 표시한다. 구성원별 이름과 색상을 수정하고, 구성원을 보관(비활성)할 수 있게 한다. 일정에 이미 사용 중인 구성원은 물리 삭제하지 않고 보관 상태로 남긴다. 데이터베이스 사용 시 모든 읽기·쓰기·삭제는 현재 `state.household.id`로 제한한다. 로컬/테스트 모드에서는 기존 구성원 localStorage 저장소를 사용한다.

### 2. JSON 백업·복원

현재 가족 공간의 공유 데이터(일정, 성장 기록, 구성원, 아기 프로필)를 버전이 있는 JSON으로 저장한다. Excel은 보고서용으로 계속 유지한다. 복원 전 파일 형식·버전·가족 식별자를 검증하고, 현재 가족 공간과 일치하지 않으면 중단한다. 기본 복원 방식은 미리보기 후 기존 데이터를 덮어쓰지 않고 새 기록으로 추가하는 방식으로 한다. 원격 저장 시 모든 insert는 현재 `household_id`를 강제로 주입하며 입력 파일의 household id를 신뢰하지 않는다.

### 3. 가족 공간 관리

설정에 현재 가족 공간 이름, 로그인 계정, 구성원 수를 요약한다. 초대 링크 복사/공유와 로그아웃은 기존 계정 동작을 재사용한다. 가족 공간 이름 변경, 나가기, 삭제는 별도 확인 단계가 필요한 후속 범위로 두고 이번 구현에서는 읽기·공유·로그아웃만 제공한다.

## 화면 구조

설정 화면은 다음 순서의 카드로 구성한다.

1. 가족 정보(기존)
2. 가족 구성원(신규, 목록 기본 표시·편집 영역 접기)
3. 가족 공간(신규, 현재 공간 요약·초대·로그아웃)
4. 데이터 관리(신규 JSON 백업·복원 + 기존 Excel 내보내기)
5. 화면 테마(기존)

각 신규 카드의 보조 설명과 상태는 10~12px로 유지하고, 버튼은 최소 44px 터치 영역을 사용한다.

## 데이터 경계

- 원격 질의는 반드시 `.eq('household_id', state.household.id)`를 포함한다.
- 백업·복원 payload에는 `schemaVersion`, `householdFingerprint`, `exportedAt`, `tables`를 포함한다.
- fingerprint는 초대 코드나 토큰이 아닌 현재 household id의 비가역 축약값으로 만든다.
- `private_entries`, 인증 토큰, 초대 코드 원문, 사진 경로는 백업에 포함하지 않는다.
- 복원 중 한 테이블이라도 실패하면 후속 테이블을 쓰지 않고 사용자에게 실패를 알린다. 원격 다중 테이블 트랜잭션이 없으므로 복원은 append-only이며 실패 시 재시도 가능한 상태로 둔다.

## 오류 처리

- 로그인/가족 공간이 없으면 원격 관리 버튼은 비활성화하고 현재 저장 경계를 안내한다.
- 잘못된 파일, 다른 가족 파일, 지원하지 않는 버전은 파일을 쓰기 전에 거부한다.
- 구성원 이름 중복·빈 이름·지원하지 않는 색상은 저장하지 않는다.
- 삭제 대신 보관을 기본값으로 사용해 기존 일정의 표시가 깨지지 않게 한다.

## 검증

- 정적 계약 테스트로 모듈 로드, household 범위, 백업 schema, 개인정보 제외를 확인한다.
- 순수 helper 테스트로 fingerprint, payload 검증, JSON 직렬화를 확인한다.
- 기존 설정 Excel 테스트와 전체 관련 Vitest를 실행한다.
- 브라우저에서 설정 탭의 카드 순서, 구성원 편집, 백업 다운로드, 잘못된 파일 차단을 확인한다.
