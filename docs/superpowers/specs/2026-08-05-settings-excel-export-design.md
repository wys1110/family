# 설정 탭 Excel 데이터 내보내기 설계

## 목표

설정 탭에서 현재 로그인한 사용자가 소속된 가족 그룹의 데이터를 Excel 파일로 내려받을 수 있게 한다.

## 범위

- 현재 가족 그룹 범위의 일정, 성장 기록, 아기/수유 기록, 할 일, 가족 구성원 데이터를 시트별로 내보낸다.
- 파일은 브라우저에서만 생성하고 Supabase Storage나 서버에 저장하지 않는다.
- 인증 토큰, 내부 운영 메타데이터, 원본 사진 파일은 포함하지 않는다.
- 현재 사용자가 RLS로 읽을 수 없는 다른 가족 그룹 데이터는 조회하거나 포함하지 않는다.

## 사용자 경험

- 설정 탭에 `데이터 내보내기` 카드와 `Excel(.xlsx) 다운로드` 버튼을 추가한다.
- 카드에는 포함 시트 목록과 마지막 다운로드 시각을 표시한다.
- 다운로드 중에는 버튼을 비활성화하고, 실패하면 파일을 생성하지 않은 채 재시도 안내를 표시한다.
- 빈 데이터셋도 헤더가 있는 시트로 포함해 Excel에서 구조를 확인할 수 있게 한다.

## 기술 설계

- 기존 Supabase 클라이언트와 현재 세션을 사용한다.
- 각 도메인 테이블을 현재 사용자의 가족 그룹 범위로 조회한다. 기존 RLS 정책이 범위를 보장하며, 클라이언트는 `household_id`를 임의로 확장하지 않는다.
- 외부 SheetJS 의존성은 추가하지 않는다. 필요한 OOXML 파트를 ZIP(무압축)으로 묶어 정식 `.xlsx` 파일로 다운로드한다.
- 셀 값은 XML escaping하며, 날짜는 `yyyy-mm-dd hh:mm` 형식의 문자열로 저장한다. 수유량·성장 수치 등 숫자는 숫자 셀로 저장한다.
- 서버에는 export 로그나 파일을 저장하지 않는다. 다운로드 성공 여부는 화면에만 표시한다.

## 오류 및 보안

- 인증 세션이나 가족 그룹이 없으면 버튼을 숨기고 안내 문구를 표시한다.
- Supabase 조회가 하나라도 실패하면 다운로드를 중단하고 오류를 표시한다.
- 민감한 원문 메모·사진 경로·인증 정보는 전용 export 매핑에서 제외한다.
- Blob URL은 다운로드 직후 해제한다.

## 검증 기준

- 설정 탭에 export 카드와 Excel 버튼이 표시된다.
- 워크북에 정의된 시트와 헤더가 항상 존재한다.
- 현재 가족 그룹 범위와 제외 필드가 코드 계약 테스트로 고정된다.
- 다운로드 성공·실패·빈 데이터 경로를 테스트한다.
