# 부드러운 모바일 모션 디자인

## 목표

가족 앱의 화면 전환을 iPhone Safari에서도 끊김과 잔상 없이 보이도록 단순화한다. 화려함은 속도감 있는 좌우 이동 한 가지에 집중하고, 콘텐츠를 읽거나 버튼을 누르는 데 방해되는 효과는 제거한다.

## 모션 원칙

- 탭 전환은 220ms의 짧은 좌우 이동과 페이드만 사용한다.
- `blur`, 3D 회전, 원근 이동, 네온 그림자, 카드별 순차 등장은 사용하지 않는다.
- 팝업은 240ms 동안 아래에서 18px 올라오며 나타난다.
- 하단 FAB는 상시 고정하고 눌렀을 때만 96%로 축소한다.
- 애니메이션에는 합성이 안정적인 `transform`과 `opacity`만 사용한다.
- `prefers-reduced-motion: reduce`에서는 전환을 80ms 페이드로 축소한다.

## 범위

- `motion-system.css`: 화면, 카드, 팝업, FAB 모션을 단순화한다.
- `motion-system.js`: 기존 탭 전환 제어는 유지하되 카드 진입 클래스는 더 이상 사용하지 않는다.
- 테마, 월페이퍼, 데이터, 화면 레이아웃은 변경하지 않는다.

## 검증

- 계약 테스트로 금지된 블러·3D·네온·카드 진입 모션의 부재를 고정한다.
- 390x844 화면에서 일정과 성장 탭을 왕복하고 FAB와 팝업을 확인한다.
- 전체 테스트와 정적 검사를 실행한다.
