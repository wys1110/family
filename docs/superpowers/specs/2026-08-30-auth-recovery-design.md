# 가족 앱 인증 세션 복구 설계

## 문제

운영 브라우저에서 Supabase 세션 객체는 존재하지만 PostgREST 요청이 `401`을 반환했다. 현재 앱은 이 오류를 네트워크 오류로만 처리하고 세션을 갱신하지 않는다. 그 결과 가족 공간 조회가 실패하고, 빈 기본 상태를 정상 화면처럼 렌더링하며, 알림·할 일·활동 로그도 같은 인증 상태로 연속 실패한다.

## 결정

`family-auth.js`에 인증 오류 판별과 단일 비행(single-flight) 세션 갱신·1회 재시도 기능을 둔다.

- 응답 오류가 인증 오류인지 `status`, PostgREST 인증 코드, JWT 만료 메시지로 판별한다.
- 동시에 여러 요청이 `401`을 받아도 `refreshSession()`은 한 번만 실행한다.
- 갱신 성공 시 모든 대기 요청은 각자의 원래 작업을 한 번만 재시도한다.
- 갱신 실패 시 `family:auth-expired` 이벤트를 발행하고 앱은 세션을 비운 뒤 로그인 게이트를 보여준다.
- 인증 오류가 아닌 오류는 기존 동작과 메시지를 유지한다.
- 기존 로컬 저장 데이터나 Supabase RLS 정책은 변경하지 않는다.

## 적용 범위

- 앱 초기 `household_members` 조회와 초기 가족 데이터 조회
- 앱의 가족 일정·아기·성장·월페이퍼 DB/Storage 읽기와 쓰기
- 가족 할 일 조회·기록·수정·삭제
- 알림·활동 로그 조회/기록
- 새 인증 모듈은 `index.html`에서 `app.js`보다 먼저 로드하고 서비스 워커에서 네트워크 우선으로 전달한다.

## 사용자 경험

일시적인 만료 토큰은 화면 전환 없이 자동 복구한다. 복구할 수 없는 세션만 기존 가족 데이터가 남아 있는 것처럼 보이지 않도록 즉시 로그인 상태로 전환하고 `로그인이 만료됐어요. 다시 로그인해 주세요`를 표시한다.

## 검증

Vitest로 인증 오류 판별, 동시 갱신 1회, 성공 재시도, 갱신 실패 이벤트를 고정한다. 이후 전체 테스트·정적 검사·diff 검증과 공개 배포 화면에서 인증 오류가 반복되지 않는지 확인한다.
