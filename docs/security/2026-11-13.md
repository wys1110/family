- **BACKUP-01 / Low — 로컬 백업 일정의 HTML 삽입.** 데모에서 가족 관리자 권한으로 같은 데모 가족 식별자를 가진 합성 백업을 검사·복원했다. `settings-backup.js:68-78`의 파일 형식·가족 검사를 통과한 일정 시간 문자열이 `settings-family-management.js:280-286,312-332`를 거쳐 로컬 저장소에 남고, `app.js:1231-1243`의 `innerHTML`에 그대로 들어갔다. 입력은 동작 없는 HTML 표식이었으며 스크립트 실행과 로그인 데이터 접근은 검증하지 않았다. 확인된 경로에는 사용자가 데모에서 조작된 파일을 선택하고 복원에 동의하는 과정이 필요하다. 원격 일정의 시간 필드는 PostgreSQL의 `time` 타입이다(`supabase/schema.sql:56`).
