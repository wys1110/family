## 인증과 가족별 데이터 격리

- 세션 갱신 전후에 사용자 문맥이 바뀌면 이전 요청의 응답을 폐기하는지 확인했다. 계정 전환 뒤 도착한 이전 요청의 실패가 새 세션을 만료시키지 않는 경우도 합성 테스트에서 통과했다. `family-auth.js:97–133`, `test/family-auth.test.js:254–355`.
- 반복 할 일은 부모 항목과 같은 가족인지, 부모가 비공개라면 현재 사용자가 작성자인지 검사한다. 두 가족에 모두 가입한 사용자도 가족을 가로지르는 부모 관계를 생성할 수 없음을 로컬 DB에서 확인했다. `supabase/migrations/20261109032643_secure_todo_recurrence_parent.sql:21–49`, `test/todo-recurrence-isolation.test.js:59–117`. [Supabase 행 수준 보안 지침](https://supabase.com/docs/guides/database/postgres/row-level-security)
- 수면 종료·취소에서는 다른 가족의 세션과 존재하지 않는 세션이 같은 결과를 반환했다. 수면 기록 저장에 실패하면 종료 처리도 함께 롤백되는 회귀를 확인했다. `test/sleep-record-isolation.test.js:77–100`.
- 기존 **SESSION-01 / Medium**은 계정을 바꿀 때 남아 있는 일정 일괄 입력 초안과 관련된다. 관련 소스 변경이 없어 미해결 상태를 유지한다. 이번 점검의 세션 갱신 테스트는 이 초안의 저장 경로까지 다루지 않는다. [기존 점검](2026-11-20.md)
