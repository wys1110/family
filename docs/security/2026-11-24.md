## 파일 배포와 브라우저 입력

- 자장가 재생기는 브라우저에 저장한 곡 ID를 미리 정한 세 곡과 대조한 뒤 해당 파일 경로를 사용한다. 상태 문구와 곡 이름은 `textContent`와 `Option`으로 표시한다. 업데이트는 현재 페이지 URL에서 버전 매개변수를 바꿔 다시 연다. `lullaby.js`, `app-update.js`. [프런트엔드 보안 점검 기준](https://github.com/openai/skills/blob/main/skills/.curated/security-best-practices/references/javascript-general-web-frontend-security.md)
- Pages 배포 과정은 `assets/` 폴더 전체를 공개 빌드로 복사한다. 이번 자장가와 가족 앱 아이콘은 공개 데모에도 제공하기로 한 정적 파일이다. 이 폴더에는 비공개 가족 사진을 넣지 않아야 한다. `scripts/prepare-capacitor.mjs`, `.github/workflows/pages.yml`.
- 합성 데이터로 계정이 바뀌는 도중 진행 중이던 사진 삭제를 중단하고, 다른 기록이 참조하는 파일을 보존하는 동작을 확인했다. 사진 관련 테스트 두 파일과 자장가·화면 테스트 두 파일에서 총 27건이 통과했다. `test/account-photo-context.test.js`, `test/shared-photo-cleanup.test.js`, `test/continuous-lullaby.test.js`, `test/simple-family.test.js`.
