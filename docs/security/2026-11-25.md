## 변경 코드와 요청 처리

- 달력 위 버튼 행을 제거한 코드는 기존 버튼을 성장 화면으로 옮긴다. 새 HTML을 조립하던 부분이 줄었고 사용자 입력을 받는 경로나 권한 검사는 바뀌지 않았다. [PR #262](https://github.com/wys1110/family/pull/262)
- 공개 빌드는 로컬 `config.js`의 SHA-256 앞 16자리를 고정된 상대 경로의 버전 값으로 쓴다. 이 값은 브라우저 캐시 갱신에 사용한다. 패키징 테스트에서 설정 파일이 바뀌면 주소도 달라지고, 가상 비밀 파일·개발 도구·서버 스크립트가 배포 목록에서 빠지는 것을 확인했다. [PR #263](https://github.com/wys1110/family/pull/263) · [프런트엔드 보안 점검 기준](https://github.com/openai/skills/blob/main/skills/.curated/security-best-practices/references/javascript-general-web-frontend-security.md)
- `scripts/parenting-codex-server.mjs`는 채팅 요청의 출처와 토큰, 대화 길이·역할 순서를 확인한다. 대화 내용은 고정 실행 인자와 분리해 표준입력으로 보낸다. 기존 테스트는 임시 폴더와 모의 응답으로 요청 거부 및 연결 종료 시 정리를 확인했다. 기존 큐의 Low 항목은 계속 추적한다. [이전 큐 점검](2026-11-19.md)
