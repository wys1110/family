## Low · 동화 속 이름 편집창에 남는 입력값

**STORY-01 · 미해결 · 코드에서 확인.** 이름 편집창을 연 상태에서 같은 브라우저의 로그인 계정이 바뀌면, 화면의 미리보기는 새 계정에 맞춰 갱신되지만 열린 입력란에는 이전 이름이 남을 수 있다. 이 상태에서 저장하면 새 계정의 브라우저 설정에 이전 이름이 기록될 수 있다. 설정은 기기 내에 저장한다. 이 처리 방식은 이번 동화 변경 전부터 있었다. 후속 수정 시에는 계정이 바뀌면 편집창을 닫고 대기 중인 저장도 취소하는 편이 맞다. 실사용 계정 전환이나 실제 정보 노출은 확인하지 않았다. ## 검증

Node 22에서 전체 149개 파일의 테스트 1,039건과 `npm run check`가 통과했다. 운영 Pages에서 데모 HTML·동화 코드·삽화·음원 등 11개 응답이 모두 HTTP 200이었고 로컬 배포 파일과 바이트 단위로 일치했다. 독립 WebKit 세션에서 공개 그림책의 4장을 열어 무음으로 시작하고 읽기를 누르면 해당 장의 음성 위치에서 재생되는 것을 확인했다. 운영 로그인, 가족 기록, DB 접근 정책은 이번 범위에 포함하지 않았다. 변경 파일은 이 보고서 한 건이다.
