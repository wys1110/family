## 가족 초대와 권한

- 가족 구성원도 유효한 초대 링크를 공유할 수 있다. 초대 링크를 연 사람은 참여 버튼을 눌러야 가입 절차가 진행된다. 코드 갱신과 구성원 제외는 소유자 권한이다. DB의 구성원 제외 함수는 별도로 호출자가 소유한 가족을 조회하고 그 가족에 속한 일반 구성원만 제외한다. 구성원을 제외하면 같은 트랜잭션에서 이전 초대 코드가 만료되도록 코드를 교체한다. [권한 표시](../../family-permissions.js) · [가입·구성원 제외 함수](../../supabase/migrations/20261025094000_revoke_removed_member_invites.sql)
- 메모리 DB에 가상 가족을 만든 기존 테스트에서 초대 만료·교체, 제외된 구성원의 이전 초대 거부, 소유자 보호, 구성원 제외와 초대 교체의 동시 롤백이 통과했다. 스키마에는 가족·구성원·일정 테이블의 행 수준 보안(RLS)이 설정돼 있다. [격리 테스트](../../test/fresh-install-invites.test.js) · [앱 스키마](../../supabase/schema.sql) · [Supabase RLS 기준](https://supabase.com/docs/guides/database/postgres/row-level-security)
- 기존 **INVITE-01**(DB 함수의 검색 경로 보강)과 **INVITE-02**(동시 가입 시 단일 가족 소속 보장, Low 후보)는 미해결이다. 이번 점검에서는 접속 권한의 운영 전제와 동시 가입 상황을 검증하지 않았다. [기존 점검](2026-11-09.md)

## 의존성과 배포 검증

- **DEP-01 · 기존 Moderate.** npm 잠금 파일 감사 결과 개발 의존성에서 전이 영향을 포함해 6개 패키지가 집계됐다. High·Critical은 0개였고, 개발 의존성을 제외한 감사도 0개였다. 외부 CDN 자산은 이 수치에 포함되지 않는다. [glob 공지](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) · [minimatch 공지](https://github.com/advisories/GHSA-g3hv-75wg-m249) · [uuid 공지](https://github.com/advisories/GHSA-w5hq-g745-h8pq)
- Node 22에서 전체 테스트 996건(148개 파일)과 `npm run check`가 통과했다. 공개 데모 HTML, 설정 파일, 가족 온보딩·권한 스크립트는 모두 HTTP 200을 반환했고 기준 커밋의 배포 예상 내용과 일치했다.
- 개인 계정 로그인·실제 가족 초대·운영 DB 정책은 검증 범위 밖이다. 이번 정기 점검의 변경은 이 보고서 한 건이다.
