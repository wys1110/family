- 심각도: 높음/중간, 개발 환경에 한정된 의존성 경고. 이 앱에서 실제 악용되는 경로는 재현하지 않았다.

- 영향: 개발 서버가 노출된 환경의 mock 코드 주입/경로 접근, 악의적 source map 처리에 따른 서비스 거부 등. 배포된 정적 앱에 테스트 서버가 포함된다는 증거는 없다.
- 조치: 호환 패치 버전과 잠금 파일 갱신. npm audit fix --force, 메이저 다운그레이드, 임의 override는 사용하지 않았다.
