Critical 외 수정 제한에 따라 패키지를 유지하며 개발 도구의 호환 업데이트 검증은 미해결이다.
- **HARDEN-01 / Medium, 방어 계층 보강:** `index.html:615`는 `@supabase/supabase-js@2` CDN 스크립트를 integrity 없이 로드한다. 공개 HTML의 CSP meta와 실제 HTTP 응답의 CSP 헤더도 확인되지 않았다. 기존 코드의 공급망/XSS 방어 보강 항목이며 CDN 변조나 실행 가능한 XSS를 재현한 발견은 아니다. 정확한 버전 고정·SRI 또는 자체 호스팅, 호환성을 검증한 CSP가 개선 방향이다. 이번 제한에 따라 수정하지 않았다. 이미 로드된 신뢰 스크립트의 동작까지 CSP 하나로 보장할 수는 없다.
- **AUTH-01 / Low, 합성 재현·실기 조건 미확인:** `native-bridge.js:69-79`의 오류 콜백은 URI와 앱의 pending 상태를 검사하지만, 그 오류가 현재 로그인 거래에서 발생했는지는 연결하지 않는다. 로그인 대기 중 정확한 주소에 `?error=access_denied`를 전달한 독립 VM 점검에서 pending 제거·브라우저 닫기 1회·이후 정상 코드 교환 0회를 확인했다. 외부 앱/웹이 실기에서 이 딥링크를 전달할 수 있다면 로그인을 중단시켜 재시도를 유발할 수 있다. 계정 접근·토큰 유출은 재현되지 않았으며 로그인 거래와 오류를 결합하거나 미결합 오류의 자동 취소를 제한하는 것이 개선 방향이다. 실제 외부 전달 조건은 미확인이며 Critical-only 제한으로 수정하지 않았다.
