# 가족 웹 안의 내 자산 — 검토용 시안

사용자가 기존 Apps Script 화면을 교체하고 웹을 하나로 합치길 요청해, 가족 사이트의 `assets.html`로 자산 화면을 옮기는 변경을 준비했다. 기존 가족 홈을 유지한다는 기본안으로 작업했으며, 새 통합 홈을 선택한 사용자 답변은 아직 없다. 실제 적용 전 시안 검토가 필요하다.

## 범위

- 기존 계정 메뉴의 내 자산 링크 → 같은 사이트 내부 페이지. 가족 로그인 세션을 공유한다.
- 요약, 자산·부채, 거래의 세 메뉴. 거래 검색·기간/사용 범위 필터·페이지 이동, 잔액/거래 추가·수정 및 저장 전 확인.
- 기존 자산 화면의 흰색·회색·파란색과 한국어 시스템 글꼴을 유지한다. 가족 홈·기존 가족 테마의 디자인은 바꾸지 않는다. 전용 색은 기존 `theme-system.css`의 `html[data-family-page="private-assets"]`에 한정한다.
- 390px 모바일에서 금액이 줄바꿈되지 않도록 세로 행으로 배치하고, 데스크톱에서는 세 열로 표시한다. 오래된 합계를 최신 잔액으로 제시하지 않는다.
- 금액 미확인, 부분월, 날짜·통화가 다른 잔액, 부분 순자산을 구분한다. 실제 은행 연결이나 새 금융 추정 기능은 없다.
- 가리기·로그아웃·계정 변경·페이지 이탈 시 데이터와 편집 값을 제거한다. 금융 기록은 브라우저 저장소에 저장하지 않는다.
- 저장 응답이 끊기면 같은 요청 ID로 재확인한다. 성공 처리 후 원장을 다시 읽으며, 재조회 실패는 별도로 표시한다.

## 시안과 검증

`test/fixtures/private-assets-preview.html`은 합성 데이터만 사용하며 공개 배포 묶음에서 제외된다. `?retry-save=1`, `?error=1`, `?signed-out=1`, `?loading=1`로 제한된 상태를 재현할 수 있다. 합성 화면의 수치는 실제 자산·지출·예산이 아니다.

- [모바일 시안](preview/private-assets-mobile.jpg)
- [데스크톱 시안](preview/private-assets-desktop.jpg)
- 로컬 미리보기: `python3 -m http.server 8757 --bind 127.0.0.1` 실행 후 `/test/fixtures/private-assets-preview.html`.
- 브라우저에서 검색, 추가·저장·재조회, 불확실 응답 재시도의 중복 방지(60건 → 61건, 새 항목 1개), 가린 뒤 DOM/입력 값 제거, 로그인하지 않은 실제 페이지 차단을 확인했다.
- 390×844 및 1100px 시안을 확인했다. 최종 모바일 요약에는 가로 넘침과 금액 줄바꿈이 없었다. 실제 iPhone 기기 검증은 하지 않았다.
- 독립 검토 결과: 검토용 PR/시안 공개 가능. 운영 인증·실제 Drive 읽기/저장의 검증 완료를 뜻하지 않는다.

## 적용 전 남은 단계

화면과 [서버 연결 방식](private-assets-connection.md)을 검토받은 다음 별도 Apps Script API 배포·서버 비밀 설정을 활성화하고 실제 본인/다른 계정의 권한 및 원장 읽기·저장 흐름을 검증해야 한다. 현재 UI와 서버 코드는 배포하지 않았고 기존 서비스는 유지 중이다. 이 변경만으로 서버 권한이나 Drive 공유 범위가 바뀌지 않는다.
