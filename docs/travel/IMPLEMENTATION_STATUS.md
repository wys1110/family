# 여행 탭 구현 상태

2026-09-21 기준으로 설계의 1차 출시 범위를 기존 vanilla JS/PWA 구조에 붙였다.

## 동작하는 범위

- 일정 / 성장 / 여행 / 동화 / 설정 / 관리 탭 순서와 여행 탭 지연 로딩
- Nova 밝음·어두움 테마를 사용하는 모바일·데스크톱 여행 화면
- 여행 생성·여행 정보 수정, 성인·아동·유아·객실 수, 날짜와 선택 예산
- 항공·숙소 외부 검색 링크, HTTPS 수동 예약처 링크 검증
- 조건별 후보 저장(종류별 현재 조건 최대 3개), 비교 선택·제외, 예약 등록
- 날짜별 일정, 주소·좌표 기반 순서 미리보기, 카드·핀 선택, 위/아래 순서 변경, Google Maps 길찾기
- 가족 준비 체크리스트, 여행별 지출, 날짜별 메모 기록
- `?demo=1` 전용 로컬 데모 데이터와 일반 모드의 가족 컨텍스트별 로컬 저장

## 아직 외부 설정이 필요한 범위

- 현재 여행 데이터는 브라우저 로컬 저장소 기반이다. Supabase 테이블/RLS 마이그레이션은 별도 승인 후 연결한다.
- Skyscanner·Booking.com 실시간 가격 API와 Google Maps SDK/Routes는 제휴·키·쿼터 설정 전까지 외부 검색과 경로 링크로 동작한다.
- 사진 업로드, 예약에서 일정 생성 미리보기, 충돌 감지·동시 편집, 서버 검색 프록시는 후속 PR 범위다.

실시간 가격·지도·예약 완료로 오인할 수 있는 가짜 결과는 표시하지 않는다. 외부 예약처를 연 사실만으로 예약 완료 상태로 바꾸지 않는다.
