# 여행 히스토리 상단 요약

요청: 여행 탭 맨 위에 어디에 얼마나 다녀왔는지 한눈에 표시한다.

## 화면과 집계
- 기존 pageHeader 바로 아래, 여행 선택 목록 위에 작은 요약 영역을 넣는다. 빈 여행 상태에도 0회와 안내를 표시한다.
- 지난 여행 횟수, 누적 박수, 여행지 수를 3개 카드로 표시한다. 추가로 진행 중/예정 여행 횟수를 분리 표시한다.
- 여행지별 지난 여행 횟수와 누적 박수를 상위 5개 막대로 표시한다. 방문 횟수 내림차순, 동률은 박수 내림차순 및 이름 순. 숫자와 이름을 텍스트로도 제공한다.
- '종료일이 지난 일정 기준 · 박수는 시작일과 종료일의 차이'라고 집계 기준을 표시한다. 방문 체크나 보관 상태를 완료 사실로 단정하지 않는다.
- 각 여행의 timezone으로 오늘을 판단한다. 잘못된 timezone은 Asia/Seoul로 대체한다. 날짜는 엄격한 YYYY-MM-DD 실제 달력 날짜, UTC 일수 차이로 계산한다. 같은 날은 0박; 역전/누락/잘못된 날짜는 집계에서 제외하고 안내한다.
- archivedAt은 숨김 표시이므로 지난 여행 집계에는 포함한다. data.getTrips({includeArchived:true})를 이용하고 기존 선택 목록 동작은 유지한다. 중복 id는 1회만 세며 입력을 변경하지 않는다.
- 여행지는 destinationLabel/destination을 trim하여 같은 문자열별 묶는다. 비어 있으면 '여행지 미지정'으로 표시하되 여행지 수에는 포함하지 않는다. 자유 입력 이름을 도시나 국가로 임의 병합하지 않는다.
- 현재 데이터에 국가 필드가 없으므로 국내/해외를 추정 표시하지 않는다. 실제 가족 여행 기록·민감정보를 공개 JS나 테스트에 넣지 않는다.
- 최근 조회 데이터로만 클라이언트에서 계산한다. 가족 전환, 여행 수정, 원격 갱신 시 기존 render 흐름에 따라 재계산한다. DB/API/스키마 변경 없음.

## 구현과 검증
- 기존 vanilla JS/CSS 및 Nova 테마 유지. travel-data.js에 부작용 없는 집계 함수 제공, travel.js에서 렌더링. 360px 화면, 밝음/어두움 지원. 새 라이브러리/API 없음.
- test/travel-tab.test.js에 가상 데이터로 날짜/일정 상태/보관/중복/집계/시차/빈 상태 검증을 추가한다.
- config.js의 변경 모듈 버전과 index.html의 config 캐시 키를 업데이트한다. 연관 기존 테스트 기대값도 갱신한다.
- npm test와 npm run check, 실제 화면 QA. 배포는 검토 결과를 보여준 후 사용자 확인을 받는다. main push는 자동 공개 배포이므로 금지.
