# Nova design preview

Actual Chromium screenshots using isolated demo data. No production data or database was modified.

- Ivory/lavender light and navy/lavender dark palettes.
- Unified navigation, SVG icons, cards, forms and in-flow primary actions.
- Existing feature handlers, photo rendering and permissions retained.
- Theme palette: `theme-critical.css`; presentation: `nova-family.css` and `nova-family.js`.

Validation: 455 automated tests passed; syntax, TypeScript and theme-color checks passed. Calendar, growth, stories and settings have no horizontal page overflow at 320, 390, 768 and 1440 CSS pixels. Calendar/growth forms, feeding/diaper/sleep dialogs and analysis disclosure were exercised in the demo browser. Physical iPhone testing and production deployment remain pending.

The overview shows the upper portion of three screens; full screenshots are provided alongside it.
