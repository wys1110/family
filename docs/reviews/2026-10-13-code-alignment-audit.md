# 코드 안정성 및 정렬 검토 — 2026-10-13

요청: 디자인은 유지하고 코드 오류와 실제 정렬 문제를 수정한다.

## 유지한 디자인

Nova의 색상·폰트·아이콘·카드·반경·44px 조작 기준을 유지했다. CSS 변경은 `premium-ui.css`의 `body { min-width: 320px; }` 제거 한 줄뿐이다. 기존 작은 화면 규칙과 브라우저 스크롤바 폭이 함께 적용되면 본문이 가용 폭보다 커지는 원인이었다. 320px viewport에서 변경 전 scrollWidth/clientWidth는 320/305, 변경 후는 305/305다. 390px과 1280px의 기존 정렬 폭은 유지됐다.

## 코드에서 확인한 문제와 수정

- 빠른 기록을 다른 버튼으로 연속 누르면 저장이 중복됨: 다이얼로그 전체 저장 가드와 실패 후 제어 복구. 저장 중 Escape로 닫아도 완료 전 다시 열어 기존 결과가 새 창을 닫지 않도록 일반·수유 입력 경로에 같은 가드를 적용했다.
- 연속 일정 이동의 늦은 실패가 최근 이동을 되돌림: 일정별 순차 저장, 요청에 고정된 날짜·가족 정보, 실패 롤백 및 대기 해제. 다른 기록 삭제가 배열을 교체해도 대기 이동·빠른 저장이 취소되지 않으며, 대상 삭제·교체나 가족 데이터 bootstrap은 이전 작업을 무효화한다.
- 가족 전환 뒤 이전 요청 성공/인증 복구가 새 화면에 적용됨: 최초 실행과 비동기 응답·인증 복구 경계에서 현재 컨텍스트 확인.
- 핵심 모듈 다운로드 실패를 성공으로 처리하고 재시도하지 못함: 실패 태그 제거, 전체 배치 종료 확인, 기존 토스트로 실패 모듈 재시도.
- DST 또는 UTC+14에서 여행 날짜 표시·최대 기간이 저장 날짜와 달라짐: 엄격한 UTC 달력 날짜 검사와 공통 날짜 열거 함수.

## 검증 경계

주요 5개 탭 30개 조합과 입력 폼 18개 조합의 실제 화면을 검증했다. 실제 iPhone Safari·키보드·관리자 권한 화면·실계정 저장/토큰 갱신은 검증하지 않았다. 백업 복원·삭제 등의 실제 가족 데이터 변경도 수행하지 않았다. 모든 팝업·권한·오류 상태의 완전한 UI 감사로 주장하지 않는다.

카카오 지도는 별도 초안 PR #156이며 실제 계정 로그인·키/도메인 설정·배경 지도 검증이 남았다. 이 변경에서 병합하거나 배포하지 않는다. 핵심 스크립트의 네트워크 실패를 검사했으며, 임의의 스크립트 내부 런타임 예외 전체를 복구하는 로더는 추가하지 않았다.

검증: `npm test` 108 files / 582 tests 통과, `npm run check`, 변경된 adaptive-feeding 문법 및 `git diff --check` 통과. 관련 회귀 테스트는 실패 재현 후 수정으로 통과를 확인했고, 독립 검토에서 지적한 다른 일정 삭제 경합도 추가 회귀 검사로 해결했다. 최신 모듈을 다시 읽은 390px 브라우저에서 빠른 수유 창 정상 실행과 console warn/error 0을 확인했다.
